# Python Encrypt Tool

A stylish Python tool for encrypting and decrypting Python scripts using Base64.

## Features

- Encrypt Python files to unreadable Base64
- Decrypt Base64 back to Python
- Clean and simple interface
- Auto redirect to Telegram channel
- Banner and credits included
